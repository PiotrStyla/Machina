Machina - instalacja dla Windows

1. Rozpakuj paczke ZIP.
2. Kliknij dwa razy plik:
   Zainstaluj Machina.cmd
3. Windows moze pokazac ostrzezenie, bo to plik pobrany z internetu.
   Jesli ufasz nadawcy, wybierz "Uruchom mimo to".
4. Po instalacji uruchamiaj Machina z pulpitu albo z menu Start.

Instalator nie wymaga konta programisty, terminala ani pnpm.
Do dzialania potrzebny jest Microsoft Edge albo Google Chrome.

Adres aplikacji:
https://piotrstyla.github.io/Machina/

Uwaga o danych:
Ta wersja zapisuje dane w przegladarce na tym komputerze, chyba ze wlaczona
jest synchronizacja Supabase w opublikowanej aplikacji.

Odinstalowanie:
Kliknij dwa razy plik:
Odinstaluj Machina.cmd
